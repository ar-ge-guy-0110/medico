# Medico

It is a web application written for health services companies. It has a fully dynamic structure and has an admin panel. It is a secure and robust web application that has a homepage gallery about the health services company, a section showing the services and the description of the services, an about us text, a section showing the statistics of the services, a gallery showing the patient comments, a blog section, a navbar and a footer section, and an admin panel where these modules and the site are managed.
